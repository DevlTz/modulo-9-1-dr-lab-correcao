# Catálogo de incidentes

O catálogo canônico fica em [`lab/incidentes/CATALOGO.md`](../lab/incidentes/CATALOGO.md),
ao lado dos scripts. São **5 famílias**; cada equipe escolhe **3 incidentes de 3 famílias
diferentes** e escreve `provocar`/`reverter` para cada um, usando `incidentes/1-*.sh`
(família Disponibilidade) como exemplo resolvido e `TEMPLATE-*.sh` como ponto de partida.
