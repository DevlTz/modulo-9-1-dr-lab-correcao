# entregas/

Cada equipe cria sua pasta e versiona aqui as entregas e os runbooks.

```
entregas/
  equipe-A/
    D1-plano-de-teste.pdf
    D2-registro-de-execucao.pdf
    D3-relatorio-final.pdf
    runbooks/
      incidente-1.md
      incidente-2.md
      incidente-3.md
```

Os modelos em branco estão em [`../modelos/`](../modelos/). As evidências datadas ficam em
`lab/evidencias/` (geradas pelo `lab.sh`) e são referenciadas nas entregas.
